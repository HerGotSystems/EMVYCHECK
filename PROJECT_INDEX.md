# EMVYCHECK — Project Index

## Purpose

EMVY CHECK is the user's music, media and creative publishing brand.

Primary functions:

- Music publishing
- Music videos
- Streaming
- Experimental releases
- AI-assisted production

## Infrastructure

- GitHub
- Cloudflare
- Cloudflare R2
- Custom web player
- YouTube
- TikTok
- Suno workflow

## Known Direction

Music ranges from:

- Drum & Bass
- Industrial
- Experimental electronics
- Czech folk influenced works
- Orchestral hybrids
- Protest and social commentary themes

## Site Goals

- Custom player
- Fast streaming
- Strong visual identity
- No dependence on major streaming platforms

## Current Problems / Next Work

- Improve music discovery
- Improve player experience
- Better visualizer integration
- Better mobile UX
- Connect releases, videos and lyrics more cleanly

## Critical Instruction

Treat EMVYCHECK as a creative platform, not just a music website.
