# COMMERCIAL USE RIGHTS GRANT — INTERNAL OPERATIONAL TEMPLATE v0.1

**⚠️ BLANK TEMPLATE ONLY — NEVER FILL THIS COPY WITH REAL CUSTOMER DATA.
Copy it into private customer-record storage outside this public
repository before use.**

**Status: INTERNAL. Not a public page. Not automated. Not final legal text —
plain-English wording for a hand-written, one-page grant per order.**

Based strictly on `docs/FIRST-CUSTOMER-SALE-KIT-v0.1.md` (canvas-grid-public
repo) Section 8.B. Covers **one exact delivered artwork only** — never a
"Design Family" or any broader/implied set of rights. Do not use the
automated `creator-commercial-v1` licence machinery for these manual
commissions; this is a separate, hand-written grant.

**The permitted-use field below must always be filled in with the
specific agreed scope (e.g. "on packaging for Product X", "as wall art
in the Riverside branch location") — never leave it as, or reduce it to,
a vague "all business use."**

---

## Fields to fill in before sending

- `[ORDER REF]`
- `[CUSTOMER NAME / BUSINESS NAME]`
- `[ARTWORK IDENTIFICATION]` — e.g. filename(s), Art Code if applicable, short description
- `[DELIVERY DATE]`
- `[SPECIFIC PERMITTED SCOPE]` — the exact agreed commercial use — see warning above
- `[MODIFICATION PERMITTED?]` — Yes / No (state which, and any limits)
- `[EXCLUSIVE?]` — Non-exclusive (default) / Exclusive (only if separately agreed and priced — state scope and duration)
- `[ATTRIBUTION REQUIRED?]` — Yes / No (state wording if yes)
- `[DATE]` and `[GRANT VERSION]`

```
  - Use outside the specific scope stated above.
  - Any "Design Family" or set of related/derivative works beyond the

Exclusivity:
  [EXCLUSIVE?]

Attribution:
  [ATTRIBUTION REQUIRED?]

Customer confirmation:
"I confirm I have received the artwork identified above and accept the
terms of this commercial use grant, limited to the scope stated."

[ Customer name / date / reply-confirmed or signed ]
```

## Notes for whoever issues this

- Never issue this grant with a vague scope. If the customer's actual
  need is broader than what you can precisely describe, have that
  conversation and price it explicitly before issuing the grant —
  do not paper over an unclear scope with generic wording.
- One grant per one delivered artwork. A different artwork, or a wider
  scope later, needs its own new grant (and, if it's a materially
  different/larger commercial arrangement, likely its own quote).
- Exclusivity, territory, manufacturing rights, white-label use, and
  large/unusual commercial arrangements need Mike's explicit decision
  and pricing before this grant is issued (see
  `docs/EMVY-BUSINESS-FRONT-DOOR-v0.1.md`'s "NEEDS MIKE DECISION" list).
- Keep the customer's confirmation (reply/signature) in the private
  order folder outside this repository.
- This wording has not been reviewed by a lawyer. Treat it as a
  reasonable, honest plain-English grant for early manual commissions,
  not as guaranteed-enforceable legal drafting, especially for
  higher-value or unusual commercial deals — flag those to Mike before
  issuing.
