# PERSONAL USE RIGHTS GRANT — INTERNAL OPERATIONAL TEMPLATE v0.1

**⚠️ BLANK TEMPLATE ONLY — NEVER FILL THIS COPY WITH REAL CUSTOMER DATA.
Copy it into private customer-record storage outside this public
repository before use.**

**Status: INTERNAL. Not a public page. Not automated. Not final legal text —
plain-English wording for a hand-written, one-page grant per order.**

Based strictly on `docs/FIRST-CUSTOMER-SALE-KIT-v0.1.md` (canvas-grid-public
repo) Section 8.A. Covers **one exact delivered artwork only** — never a
"Design Family" or any broader/implied set of rights. Do not use the
automated `creator-commercial-v1` licence machinery for these manual
commissions; this is a separate, hand-written grant.

---

## Fields to fill in before sending

- `[ORDER REF]`
- `[CUSTOMER NAME]`
- `[ARTWORK IDENTIFICATION]` — e.g. filename(s), Art Code if applicable, short description
- `[DELIVERY DATE]`
- `[MODIFICATION PERMITTED?]` — Yes / No (state which)
- `[DATE]` and `[GRANT VERSION]` — normally `v1` unless reissued

## Template text

```
EMVY CHECK — Personal Use Rights Grant

Order reference: [ORDER REF]
Grant date: [DATE]
Grant version: [GRANT VERSION]

Artwork: [ARTWORK IDENTIFICATION]
Delivered to: [CUSTOMER NAME]
Delivery date: [DELIVERY DATE]

Granted by: EMVY CHECK (Michal Veltruský) — emvycheck@gmail.com

Permitted use:
  Personal, non-commercial use only. This includes, for example,
  printing for your own home, personal gifts, and personal (non-business,
  non-monetised) social sharing.

Modification:
  [MODIFICATION PERMITTED?] — you may / may not adapt, crop, recolour
  or otherwise modify the delivered file(s) for your own personal use.

Not permitted, unless separately agreed in writing:
  - Resale of the raw artwork file, in original or modified form.
  - Sublicensing this artwork to anyone else.
  - Any commercial or business use (see COMMERCIAL-USE-RIGHTS-GRANT-v0.1.md
    if you need this).
  - Claiming this artwork as your own original creative work.

Exclusivity:
  Non-exclusive. EMVY CHECK may continue to use, develop, licence or
  sell related or similar work, including variations from the same
  Recipe/Art Code.

Attribution:
  No attribution/credit is required from you for personal use.

Scope:
  This grant covers the one artwork identified above only. It does not
  extend to any other artwork, variation, or future work, and does not
  transfer copyright or ownership — EMVY CHECK / Michal Veltruský remains
  the copyright holder. This is a usage licence, not a sale of the
  underlying rights.

Customer confirmation:
"I confirm I have received the artwork identified above and accept the
terms of this personal use grant."

[ Customer name / date / reply-confirmed or signed ]
```

## Notes for whoever issues this

- Fill in the artwork identification precisely — one grant per one
  delivered artwork.
- If the customer later wants commercial use of the same artwork, that
  needs a separate `COMMERCIAL-USE-RIGHTS-GRANT-v0.1.md`, not an edit to
  this one.
- Keep the customer's confirmation (reply/signature) in the private
  order folder outside this repository — this is the approval evidence.
- This wording has not been reviewed by a lawyer. Treat it as a
  reasonable, honest plain-English grant for early manual commissions,
  not as guaranteed-enforceable legal drafting. Flag to Mike if a
  customer requests changes beyond filling in the fields above.
