# ORDER CONFIRMATION — INTERNAL OPERATIONAL TEMPLATE v0.1

**⚠️ BLANK TEMPLATE ONLY — NEVER FILL THIS COPY WITH REAL CUSTOMER DATA.
Copy it into private customer-record storage outside this public
repository before use.**

**Status: INTERNAL. Not a public page. Not automated. Copy this into an email/document per order.**

Based strictly on `docs/FIRST-CUSTOMER-SALE-KIT-v0.1.md` (canvas-grid-public repo) Sections 5 and 9, and the current manual order model:

`ENQUIRY → QUOTE → CUSTOMER CONFIRMATION → PREVIEW/WORK → INVOICE/PAYMENT → FINAL FILES + WRITTEN RIGHTS`

Use this after the intake questionnaire (Sale Kit §4) and before starting preview work. Send it to the customer and get the confirmation line back (reply, signature, or a clear written "yes") before doing paid work.

---

## Fields to fill in before sending

- `[ORDER REF]` — e.g. `EC-2026-001` (see Sale Kit §10 numbering)
- `[CUSTOMER NAME]`
- `[PROJECT — one line]`
- `[INTENDED USE]` — Personal / Small business commercial / Broader commercial (see Sale Kit §2)
- `[PRICE]` — current introductory test price for that use category
- `[NUMBER OF PREVIEWS]` — normally 2–4
- `[ROUNDS OF ADJUSTMENT]` — state the number agreed
- `[DELIVERY FILE TYPES]` — e.g. PNG / panel files, as applicable
- `[TARGET DELIVERY TIME]` — e.g. "X days after preview approval and payment"
- `[PAYMENT METHOD]` — **Mike to confirm current method** (bank transfer / other agreed business payment method); do not invent one
- `[DATE]`

## Template text

```
EMVY CHECK — Order Confirmation

Order reference: [ORDER REF]
Date: [DATE]

Customer: [CUSTOMER NAME]
Project: [PROJECT — one line]
Intended use: [INTENDED USE]

Price: £[PRICE]
These are introductory test prices while EMVY CHECK takes on its first
few commissions.

What's included:
  - [NUMBER OF PREVIEWS] preview options
  - 1 final chosen artwork, high-resolution file(s)
  - [ROUNDS OF ADJUSTMENT] round(s) of small adjustments before final delivery
  - A written usage-rights grant matching the intended use above
    (see PERSONAL-USE-RIGHTS-GRANT-v0.1.md or
    COMMERCIAL-USE-RIGHTS-GRANT-v0.1.md)

Delivery files: [DELIVERY FILE TYPES]
Target delivery: [TARGET DELIVERY TIME]

Payment terms: £[PRICE] via [PAYMENT METHOD], invoice provided,
due before final file delivery.

Usage-rights category: [INTENDED USE]

What this order does NOT include, unless separately agreed and priced:
  - exclusivity
  - a "Design Family" or any set of artworks beyond the one delivered
  - transfer of IP ownership (this is a usage licence, not a sale of
    copyright)
  - sublicensing or resale of the raw artwork file

Customer confirmation:
"I confirm the above description, price, and usage rights are correct
and I'd like to proceed."

[ Customer name / date / reply-confirmed or signed ]
```

## After confirmation

- File the customer's confirmation reply (email/message/signature) — this is the approval/date evidence for the order. Keep it in the private order folder outside this repository (Sale Kit §10 folder convention).
- Proceed to preview work only after this confirmation is received.
- On delivery, use `INVOICE-AND-DELIVERY-CHECKLIST-v0.1.md`.

## What this template must never become

- An automated checkout or payment flow.
- A substitute for the actual written rights grant (always send the separate grant document, not just this confirmation).
- A promise of Design Family, exclusivity, or IP transfer that was not separately agreed and priced.
