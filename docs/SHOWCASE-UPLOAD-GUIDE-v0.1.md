# EMVY CHECK — HOMEPAGE SHOWCASE UPLOAD GUIDE v0.1

Purpose: make it easy to add real Canvas Grid / EMVY CHECK artwork to `emvycheck.com` without redesigning the homepage.

## First batch

Upload 6 strong images. Prefer real exported artwork or Presentation Preview screenshots rather than tiny UI screenshots.

Suggested mix:

1. `showcase-01-hero.jpg` — strongest colourful single artwork.
2. `showcase-02-grid9.jpg` — a strong 3×3 / GRID9 piece.
3. `showcase-03-multipanel.jpg` — 5×5 or multi-panel presentation.
4. `showcase-04-calm.jpg` — quieter Gallery Calm / Soft Wash direction.
5. `showcase-05-emvy.jpg` — aggressive EMVY / Rave / poster direction.
6. `showcase-06-variation.jpg` — related variation / same design family idea.

## Image preparation

- JPG or WebP is preferred for photographs/mock-ups.
- PNG is fine for crisp artwork where file size stays reasonable.
- Aim roughly 1600–2400 px on the longest edge for homepage display.
- Do not upload production-master files merely to make a website thumbnail.
- Avoid embedding customer/private information in screenshots.

## Placement

Create a simple `showcase/` directory in the EMVYCHECK repo when the first images arrive.

The homepage section should explain that these are examples made with EMVY CHECK / Canvas Grid and that visitors can open Canvas Grid to make their own, commission work, or contact us for commercial/physical production.

Do not claim every showcased piece is registered/licensed unless it actually is.

## Captions

Keep captions short and factual, for example:

- `Canvas Grid — Op Art + Bubbles, 3×3 variation`
- `Canvas Grid — related 5×5 panel study`
- `EMVY CHECK ART — presentation mock-up`

The artwork should do most of the talking.
