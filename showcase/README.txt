Rules:
- Use web-size derivatives (roughly 1600-2400px on the long edge), not
  production-master files.
- JPG or WebP preferred; PNG is fine if the file size stays reasonable.
- Do not embed customer/private information in screenshots.
- Do not claim a piece is registered/licensed unless it actually is.

After adding the files, open showcase.js in the repo root and fill in
the matching "image" field for each item (leave it as "" for any slot
you have not filled yet — the homepage safely shows nothing extra for
empty slots, never a broken image box or stock placeholder). Update the
"caption" field with a short, factual description if you want something
more specific than the default.
